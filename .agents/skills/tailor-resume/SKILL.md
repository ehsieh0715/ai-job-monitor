# Prepare a job-specific CV

Read `policies/evidence-policy.md`, `policies/job-evaluation.md`,
`policies/resume-writing.md` and `policies/resume-review.md` from the repo root.
Resolve Career paths from `config/config.local.yaml` using `config/README.md`.

1. If application value has not been assessed for the current JD/evidence, assess
   it using evaluate-jobs' conversation mode. Use the same score and standards,
   compare available prior judgments and explain material changes.
2. Ask about material unknown experience; record only confirmed facts in the
   authorized Profile or relevant evidence summary. Do not invent metrics or
   assume a missing record proves lack of experience.
3. If structural/non-waivable gaps make preparation low-value, explain why and
   stop. Continue drafting only if explicitly requested despite that assessment.
4. Before drafting, require confirmation to proceed or an explicit CV request
   for this role. No Master CV or existing base is needed: select relevant facts
   from the Profile and project summaries. Old CVs are optional wording references.
5. Provide a concise positioning rationale and the complete Markdown CV. For
   edits to a supplied document show only useful Current / Proposed / Reason
   comparisons. Apply the resume-review checks and identify unresolved claims.
6. Save only when file creation/editing is requested or already authorized,
   under the configured Applications directory
   using Company Name / preparation-start-date - Job Title / CV.md. If the date,
   company or role is ambiguous, ask rather than guess. Do not overwrite submitted
   files, create extra analysis notes or export PDF unless needed/requested.
   Update the existing tracker when authorized; preserve unrelated fields.

Never modify Google Sheets, job queues, program files or shared policies as a
side effect of preparing a CV. Language and formatting preferences may change
presentation, not the evidence standard or the common assessment.
