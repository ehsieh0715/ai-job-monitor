# Write a cover letter

Read `policies/evidence-policy.md`, `policies/job-evaluation.md` and
`policies/cover-letter-writing.md` from the repo root. Resolve the local Career
configuration using `config/README.md`; read the Profile, relevant evidence and
current application CV if available. An existing CV is not required.

Assess fit first if not already assessed for the current JD/evidence. Ask about
material unknowns; apply the common provisional/eligibility/early-stop rules.
A question about letter value is not authorization to draft. Draft after the
user confirms proceeding or explicitly requests the letter for this role.

Explain briefly whether it adds value, choose 2–4 verified angles and deliver the
full letter under the policy. Research only useful company facts from reliable
official sources. Apply its truthfulness, motivation, repetition and length checks.

Save Cover Letter.md in the configured application folder only when authorized;
ask about ambiguous company/title/start date, preserve submitted versions and
export only when needed/requested. Update the existing tracker within scope.
Do not create extra JD/analysis notes or alter Google Sheets/program/policy files.
