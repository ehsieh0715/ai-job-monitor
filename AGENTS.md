# Career assistant repository

For Profile building, job evaluation, CV/cover-letter work, or a scheduled pipeline,
read `.agents/skills/career-assistant/SKILL.md`. Start with `policies/workflow.md`;
it selects stages without relying on previous conversations. Standards live only
in policies. Resolve personal paths/settings from config/config.local.yaml using
config/README.md. Never commit private inputs, outputs, preferences or credentials.
