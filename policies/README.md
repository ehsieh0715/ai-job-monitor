# Policy Guide

- Start with [career-workflow.md](career-workflow.md), [candidate-evidence-standards.md](candidate-evidence-standards.md) and private preferences when present.
- Select task-specific policies from the [workflow table](career-workflow.md#route-by-intent). Load scheduling instructions only for pipeline work.
- Read each required policy once for the current task; consult references as needed, without recursively loading every linked file.
- Candidate Profile owns personal facts, templates/CSS own presentation defaults, and private preferences record personal choices and explicit standing instructions.
- Current explicit instructions take precedence. Style choices cannot weaken evidence/scoring standards or authorize unrelated actions.
- For changes to the repo or its policies, use [CONTRIBUTING.md](../CONTRIBUTING.md).
